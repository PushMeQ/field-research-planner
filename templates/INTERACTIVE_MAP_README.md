# 交互式路线图模板

## 模板位置
- `templates/interactive-map-template.html`

## 功能特点
- ✅ 左侧信息栏：显示每日行程详情
- ✅ 右侧地图：显示点位和路线
- ✅ 点击交互：点击点位查看详情
- ✅ 距离计算：自动计算点位间距离
- ✅ 酒店标注：显示住宿酒店位置

## 使用方法

### 1. 复制模板
```bash
cp templates/interactive-map-template.html 你的项目目录/
```

### 2. 修改数据
在 HTML 文件中找到 `tripData` 数组，修改为你的点位数据：

```javascript
const tripData = [
  {
    day: 1,
    title: '第1天行程标题',
    date: '5/30',
    points: [
      { name: '点位名称', address: '详细地址', lat: 纬度, lng: 经度 }
    ],
    hotel: {
      name: '酒店名称',
      price: '价格',
      address: '酒店地址',
      phone: '电话',
      lat: 纬度,
      lng: 经度
    },
    driveTime: '行驶时间',
    distance: '距离'
  },
  // ... 更多天
];
```

### 3. 修改标题
在 HTML 文件中修改：
- `<title>` 标签
- `.sidebar-header h1` 标签
- `.sidebar-header p` 标签

## 数据格式说明

### 点位数据
```javascript
{
  name: '点位名称',      // 必填
  address: '详细地址',   // 必填
  lat: 35.52,           // 必填（纬度）
  lng: 107.35           // 必填（经度）
}
```

### 酒店数据
```javascript
{
  name: '酒店名称',      // 必填
  price: '280-350元',   // 必填
  address: '酒店地址',   // 必填
  phone: '0934-5559666', // 必填
  lat: 35.73,           // 必填（纬度）
  lng: 107.64           // 必填（经度）
}
```

## 功能说明

### 1. 左侧信息栏
- 显示每日行程详情
- 显示点位间距离和时间
- 显示酒店信息
- 点击点位可定位到地图

### 2. 右侧地图
- 显示所有点位
- 显示每日路线
- 显示酒店位置
- 支持缩放和拖拽

### 3. 控制按钮
- **显示所有点位**：缩放到显示所有点位
- **显示路线**：显示每日路线和天与天之间的连接

## 注意事项
1. 需要网络连接加载地图瓦片
2. 坐标使用 WGS84 格式（经纬度）
3. 建议使用现代浏览器打开
