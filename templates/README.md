# 田野调查行程规划模板

## 模板来源
基于甘肃考察项目的成熟方案模板。

## 模板位置
- 模板文件：	emplates/field-research-template.html
- 原始文件：projects/gansu-field-research/甘南田野调查完整方案.html

## 设计特点
1. **专业的 CSS 样式**
   - 渐变背景（hero 区域）
   - 卡片式布局（section 和 day-card）
   - 响应式设计（支持手机、平板、电脑）

2. **完整的地图功能**
   - 使用 Leaflet.js
   - 每日独立的地图
   - 全程路线总览地图
   - 支持缩放和点击

3. **详细的表格**
   - 行程概览
   - 住宿安排
   - 交通安排

4. **每日行程卡片**
   - 点位信息（带标签）
   - 详细时间安排
   - 酒店信息

## 使用方法
1. 复制模板文件
2. 修改其中的内容（点位、行程、酒店等）
3. 生成新的方案文件

## 变量说明
在模板中，以下内容需要替换：
- 项目标题
- 项目副标题
- 日期范围
- 总天数
- 总点位数
- 覆盖城市
- 交通方式
- 出行人数
- 住宿安排
- 每日行程卡片
- 生成时间

## 注意事项
1. 保持原始的设计风格
2. 使用相同的 CSS 样式
3. 使用相同的 JavaScript 函数
4. 确保地图功能正常
