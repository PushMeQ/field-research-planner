# 用户指南

## 快速开始

### 1. 安装

**Windows 用户：**
```powershell
git clone https://github.com/PushMeQ/field-research-planner.git
cd field-research-planner
.\install.ps1
```

**Mac/Linux 用户：**
```bash
git clone https://github.com/PushMeQ/field-research-planner.git
cd field-research-planner
chmod +x install.sh
./install.sh
```

### 2. 配置 API Key

1. 访问 [高德开放平台](https://lbs.amap.com/)
2. 注册账号并创建应用
3. 获取 API Key
4. 在项目目录的 `.env` 文件中配置：
   ```
   AMAP_API_KEY=your_key_here
   ```

### 3. 启动服务

**Windows：**
```powershell
.\start.ps1
```

**Mac/Linux：**
```bash
./start.sh
```

服务启动后，浏览器会自动打开 http://localhost:3000

## 使用 Skill

### 在 Claude Code 中使用

1. 打开 Claude Code
2. 输入 `/field-research-plan`
3. 按提示操作：
   - 提供点位信息（粘贴文本或文件路径）
   - 选择规划选项
   - 等待生成完成

### 在网页端使用

#### 添加点位

1. 在左侧边栏点击"点位管理"
2. 填写点位名称和详细地址
3. 点击"添加点位"按钮
4. 系统会自动进行地理编码，获取坐标

#### 规划路线

1. 点击"路线规划"标签页
2. 选择交通方式（自驾/公共交通/打车）
3. 设置每日工作时间和每个点位停留时间
4. 点击"规划路线"按钮
5. 系统会自动计算最优路线

#### 查看详情

1. 点击地图上的点位标记
2. 右侧会显示点位详情面板
3. 包含基础信息、历史背景、照片等

#### 调整路线

1. 在点位列表中拖拽点位可以调整顺序
2. 点击"重新规划"按钮更新路线
3. 可以删除或添加点位

#### 导出数据

1. 点击"导出数据"按钮
2. 选择导出格式（JSON/PDF/PNG）
3. 保存到本地

## 功能详解

### 地理编码

- **自动编码**：输入地址后自动获取坐标
- **批量编码**：支持一次性输入多个地址
- **验证机制**：自动验证坐标准确性
- **缓存机制**：编码结果自动缓存，避免重复请求

### 路线规划

- **智能优化**：使用 TSP 算法自动优化路线
- **时间估算**：根据交通方式和路况估算时间
- **每日安排**：自动生成每日行程计划
- **住宿推荐**：推荐每日住宿酒店

### 交互式地图

- **点位标记**：显示所有考察点
- **路线连线**：显示每日路线
- **详情查看**：点击查看点位详情
- **拖拽调整**：拖拽调整点位顺序
- **实时更新**：修改后自动更新路线

### 离线支持

- **自动缓存**：所有 API 调用结果自动缓存
- **离线模式**：无网时使用缓存数据
- **热点模式**：手机热点也能用
- **预加载**：出发前在家联网使用一次

## 常见问题

### Q: 安装失败怎么办？

A: 确保已安装 Node.js（版本 16+），然后重新运行安装脚本。

### Q: API Key 怎么获取？

A: 访问 https://lbs.amap.com/，注册账号后创建应用即可获取。

### Q: 离线时能用吗？

A: 可以，但需要先联网加载地图数据。建议出发前在家联网使用一次。

### Q: 支持哪些地区？

A: 支持全国所有地区，包括省、市、区县、乡镇村。

### Q: 能导出数据吗？

A: 可以，项目数据保存在 `data.json` 文件中，可以复制给团队成员。

### Q: 路线规划准确吗？

A: 路线规划仅供参考，实际路况可能有变化。建议出行前再次确认。

### Q: 住宿价格准确吗？

A: 住宿价格可能过期，建议出行前再次确认。

### Q: 能多人协作吗？

A: 可以，项目数据可以导出/导入，方便团队共享。
