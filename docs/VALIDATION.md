# 行程方案验证系统

## 验证内容

### 1. 每日工作时间验证
- **计算公式**：每日总时间 = 行驶时间 + 考察时间
- **判断标准**：是否超过用户设定的每日工作时间（默认8小时）
- **建议阈值**：
  - ✅ 合理：总时间 ≤ 8小时
  - ⚠️ 偏紧：8小时 < 总时间 ≤ 10小时
  - ❌ 超负荷：总时间 > 10小时

### 2. 行驶时间验证
- **数据来源**：高德地图 API 查询实际行驶时间
- **验证内容**：
  - 点位之间的实际距离
  - 点位之间的实际行驶时间
  - 考虑路况因素（高速/国道/山路）

### 3. 考察时间验证
- **计算公式**：考察时间 = 点位数 × 每个点位停留时间
- **验证内容**：
  - 每个点位的停留时间是否充足
  - 是否有时间拍照、记录、访谈
  - 是否有时间处理突发情况

### 4. 休息时间验证
- **判断标准**：
  - 午餐时间：至少1小时
  - 休息时间：每2-3小时休息15分钟
  - 晚上休息：至少8小时睡眠

### 5. 住宿合理性验证
- **验证内容**：
  - 住宿位置是否合理
  - 到下一个点位的距离
  - 酒店价格是否在预算内

## 验证时机

### 1. 规划完成后自动验证
- 用户确认行程安排后
- 系统自动运行验证
- 显示验证结果和建议

### 2. 用户手动验证
- 用户可以随时点击"验证行程"
- 重新计算并显示结果

### 3. 修改后重新验证
- 用户修改行程后
- 自动重新验证
- 更新验证结果

## 实现方式

### 后端验证 API
```
POST /api/route/validate
请求：
{
  "dailyPlans": [...],
  "options": {
    "dailyHours": 8,
    "stayTime": 1,
    "transportMode": "driving"
  }
}

响应：
{
  "success": true,
  "data": {
    "dailyResults": [...],
    "overallResult": {...},
    "suggestions": [...]
  }
}
```

### 前端显示
- 侧边栏显示验证状态
- 点击查看详情
- 显示优化建议
